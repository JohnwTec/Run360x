# Run360x 🏃‍♂️

Um aplicativo de corrida completo com recursos avançados para rastreamento, análise e melhoria do desempenho em atividades de running.

## 📋 Características

- 🗺️ **Rastreamento de Rotas**: Visualize suas corridas em tempo real
- 📊 **Análise de Desempenho**: Métricas detalhadas de velocidade, distância e tempo
- 📈 **Histórico de Atividades**: Acompanhe seu progresso ao longo do tempo
- 🎯 **Metas Personalizadas**: Defina e alcance seus objetivos de corrida
- 📱 **Interface Responsiva**: Funciona perfeitamente em todos os dispositivos

## 🚀 Como Começar

### Pré-requisitos

- Node.js 18+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/JohnwTec/Run360x.git

# Acesse o diretório
cd Run360x

# Instale as dependências
npm install

# Execute o projeto
npm start
```

### Variáveis de Ambiente

Crie um arquivo `.env` na raiz do projeto:

```
REACT_APP_API_URL=http://localhost:3000
# Adicione outras variáveis conforme necessário
```
